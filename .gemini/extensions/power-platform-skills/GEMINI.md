# Power Platform Skills

Use the platform-neutral skills in `skills/power-platform/`.

When a request involves Microsoft Power Platform, Dataverse, Power Apps Code
Apps, PCF controls, Dataverse plugins, Dataverse web resources, visual QA, or
browser-tab recording, read the matching `SKILL.md` from that directory before
acting. Load files from the skill's `resources/` directory only when the
`SKILL.md` says they are relevant.

If this extension is installed outside the repository, copy or link the
`skills/power-platform/` directory into the target workspace, or keep this
context file in the repository root as `GEMINI.md`.
