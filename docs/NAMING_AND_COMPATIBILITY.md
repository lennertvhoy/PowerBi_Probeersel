# Naming and compatibility

The public category is **Stateware**. The engineering method is
**State-Centric Engineering**. The portable application specification is
**StateSpec**, formerly called StateDD.

This repository changes current public and operator-facing wording only.
Existing repository and remote names, `statedd-*` commands and packages,
`.statedd` paths, schema IDs, format versions, environment variables,
persisted records, license text, branches, Git history, fixtures, and evidence
remain compatibility identifiers until a separately reviewed, versioned
migration proves dual-read behavior and rollback.

Historical records remain historically accurate. A remaining legacy term is
valid only when it is a compatibility identifier, machine identifier,
historical record, legal text, or archived reference.
