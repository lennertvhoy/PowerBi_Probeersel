# Evidence: Seed PBIP/PBIR Project Attempt

Date: 2026-05-15

## Scope

This evidence folder documents attempts to create a real seed PBIP/PBIR project
for the Fair Workload & Evaluation Cockpit.

## Current Status

**Seed PBIP NOT YET OPENING in Power BI Desktop.**

Two programmatic generation approaches were attempted in this session:
1. TMDL-based PBIP with M-expression partitions
2. TMSL-based PBIP (model.bim) with M-expression partitions

Both produced a complete folder structure, pointer files, and semantic model
definitions. Power BI Desktop launched but remained on an empty "Untitled" file
when the `.pbip` was opened, suggesting either:
- The PBIP preview feature is not enabled in this Power BI Desktop install
- Subtle schema/syntax issues in the programmatic definition

## Power BI Desktop Version

- Version: `2.153.1206.0` (April 2026)
- Install path: `C:\Program Files\Microsoft Power BI Desktop\bin\PBIDesktop.exe`

## Preview Features Status

**Not verified/enabled in this session.**
The PBIP opening behavior (always "Untitled") strongly suggests that Power BI
Desktop requires the preview feature to be explicitly enabled before it will
load a `.pbip` file:

> File → Options and settings → Options → Preview features →
> "Power BI Project (.pbip) save option"

Microsoft docs confirm PBIP is still in preview as of 2025-12.
